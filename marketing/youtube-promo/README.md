# RemoveHandwriting YouTube Promo

This folder contains a 50-second, 16:9 YouTube promotion for RemoveHandwriting.com.

- `removehandwriting-youtube-promo.mp4` — final 1080p video
- `removehandwriting-youtube-promo.srt` — upload-ready captions
- `voiceover.txt` — editable narration
- `thumbnail.png` — YouTube thumbnail
- `generate-assets.mjs` — scene generator
- `render-video.sh` — reproducible render script

The video uses product assets already present in `removehandwriting-web/public`.
